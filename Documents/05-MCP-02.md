# 🎯 Next Milestone – 5.2 MCP Gateway

In the next milestone, we will build the **MCP Gateway**, which acts as the central communication layer between our AI Service and multiple MCP Servers.

Instead of connecting the AI Service directly to every MCP Server, all requests will pass through the Gateway. This keeps the backend modular, scalable, and easy to maintain as we add more developer tools.

## 📄 registry.ts

The Registry maintains information about all available MCP Servers.

```typescript
export interface MCPServer {

    name: string;

    status: "connected" | "disconnected";

    transport: "stdio" | "http";

}
```

The Registry will help the Gateway answer questions such as:

- Which servers are available?
- Is a server connected?
- Which transport is being used?
