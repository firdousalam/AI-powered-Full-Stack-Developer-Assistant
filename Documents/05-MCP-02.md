# 🚀 Milestone 5.2 – Setting Up the First MCP Server

## 🎥 Episode 5.2

## 📌 Goal

In this milestone, we will build our **first Model Context Protocol (MCP) Server** and connect it to our **Node.js Backend**. This enables our AI-powered Full Stack Developer Assistant to interact with real project files instead of relying solely on the language model.

By the end of this milestone, our AI assistant will be capable of reading project files using the **Filesystem MCP Server**.

---

# 📖 What We Will Build

In the previous milestone, we learned the fundamentals of MCP and its architecture.

Now it's time to build our first working implementation.

Our architecture will look like this:

```text
Chrome Extension
        │
        ▼
Node.js Backend
        │
        ▼
MCP Client
        │
        ▼
Filesystem MCP Server
        │
        ▼
Local Project Files
```

---

# 📦 Step 1 – Install MCP SDK

The first step is to install the official MCP SDK.

Example:

```bash
npm install @modelcontextprotocol/sdk
```

This SDK provides the building blocks required to create both MCP Clients and MCP Servers.

---

# 📁 Step 2 – Create the Filesystem MCP Server

Create a new folder inside the backend project.

Example:

```text
backend/
│
├── mcp/
│     ├── filesystem.server.ts
│     ├── tools/
│     └── resources/
│
├── controllers/
├── services/
└── app.ts
```

The Filesystem MCP Server will expose tools that allow the AI assistant to interact with local project files.

---

# 🔧 Step 3 – Register MCP Tools

Initially, we will expose a small set of tools.

Example tools:

* Read File
* List Directory
* Check File Exists

Future milestones will introduce:

* Write File
* Create File
* Delete File
* Rename File

---

# 🔗 Step 4 – Connect the Backend as an MCP Client

Our Express backend will connect to the Filesystem MCP Server.

Flow:

```text
Express API
      │
      ▼
AI Service
      │
      ▼
MCP Client
      │
      ▼
Filesystem MCP Server
```

The backend becomes the bridge between the AI model and external developer tools.

---

# 📄 Step 5 – Read Project Files

Once connected, the AI assistant can retrieve project files.

Example:

```text
User:
Explain my package.json
```

Execution Flow:

```text
User
      │
      ▼
Chrome Extension
      │
      ▼
Node Backend
      │
      ▼
MCP Client
      │
      ▼
Filesystem Server
      │
      ▼
package.json
      │
      ▼
AI explains the project
```

Instead of guessing, the AI works with the actual project files.

---

# ⚙ Step 6 – Execute the First MCP Tool

Example flow:

```text
User asks:
Read README.md

        │
        ▼

AI Agent

        │
        ▼

MCP Client

        │
        ▼

Filesystem MCP Server

        │
        ▼

Read README.md

        │
        ▼

Return File Content

        │
        ▼

AI Generates Response
```

This confirms that our AI assistant can successfully interact with external tools.
