---

# 🤔 Why Do We Need MCP?

Large Language Models are excellent at generating text, writing code, and answering questions.

However, they **cannot directly access external resources** such as:

- Local project files
- Git repositories
- Docker containers
- Kubernetes clusters
- Databases
- Cloud platforms

Without these capabilities, AI responses are based on assumptions rather than real project data.

The **Model Context Protocol (MCP)** solves this problem by providing a standard way for AI applications to communicate with external tools.

---

# 🏗 MCP Architecture

```text
Chrome Extension
        │
        ▼
Node.js Backend
        │
        ▼
MCP Client
        │
        ▼
MCP Server
        │
 ┌──────┼──────────┬──────────┐
 ▼      ▼          ▼          ▼
Filesystem GitHub Docker Kubernetes
```

The **MCP Client** sends requests, while **MCP Servers** expose tools that interact with external systems.

---

# 🧩 MCP Components

| Component | Description |
|-----------|-------------|
| **MCP Client** | Sends requests to MCP Servers |
| **MCP Server** | Provides tools and resources |
| **Tools** | Perform actions such as reading files or executing commands |
| **Resources** | Provide data such as project files or configuration |
| **Transport** | Communication channel (stdio, HTTP, SSE) |

Instead of guessing, the AI works with actual project data.

# 📡 Communication

MCP uses **JSON-RPC** for communication between clients and servers.

A typical request looks like this:

```json
{
  "method": "tools/call",
  "params": {
    "name": "readFile",
    "arguments": {
      "path": "README.md"
    }
  }
}
```

The server processes the request and returns the result in a standardized format.

---

# 🚚 Transport Layers

MCP supports multiple communication methods:

| Transport | Use Case |
|-----------|----------|
| **stdio** | Local development (recommended) |
| **HTTP** | Remote MCP servers |
| **SSE** | Real-time streaming |

For this project, we will use **stdio** because both the backend and MCP servers run on the same machine.

---

# 🔐 Security

MCP is designed with security in mind.

Best practices include:

- Restrict filesystem access
- Validate tool inputs
- Expose only required tools
- Avoid executing arbitrary commands
- Keep sensitive credentials outside the AI model
